# janela

![version](https://img.shields.io/badge/version-v1.0.0-blue) ![license](https://img.shields.io/badge/license-MIT-green) [![GitHub](https://img.shields.io/badge/GitHub-nulljosh%2Fjanela-black?logo=github)](https://github.com/nulljosh/janela)

A web browser is a text field and a WebKit view. Everything else is opinion. A janela is a small window in a roof; this is a small window on the web.

Janela is the starting point: one window, one page, an address bar, back, forward, reload, tabs. Mac, iPhone and iPad from one SwiftUI file. Type a host and it loads, type words and it searches DuckDuckGo. No bookmarks, no sync, no telemetry. Those get added when there's a reason.
