Fenster

A web browser is a text field and a WebKit view. Everything else is opinion.

What it does

One window, one page, an address bar, back, forward, reload, tabs. Mac, iPhone and iPad from one SwiftUI file. Type a host and it loads. Type words and it searches DuckDuckGo.

Rendering, JavaScript, cookies, gestures, autofill: WebKit already does all of it. Fenster adds nothing on top until there is a reason to. No bookmarks, no sync, no telemetry.

Here on the web the frame is an iframe, so sites that refuse framing stay blank and words search Wikipedia. The real app has neither limit.
